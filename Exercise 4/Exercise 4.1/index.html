Exercise 4.1: Drawing with SVGs

This SVG demonstrates different shapes, paths, text, grouping and transformations.

SVG Features Used:

  • Shapes: rectangle, circle, ellipse, line and polygon.
  • Paths: Used for the walkway and chimney smoke.

  • Transform: translate() is used to position the windows, tree and flowers.
  • Styling: Fill, stroke and stroke width are used to style the SVG.
